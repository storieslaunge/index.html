# Lounge Bar Telegram Mini App MVP

Демо-проект: Telegram-бот, Telegram Mini App, FastAPI API, SQLite и админ-панель. API и интерфейс обслуживаются одним приложением, поэтому отдельная сборка фронтенда не нужна.

## Структура

```text
.
├── app/
│   ├── __init__.py
│   ├── bot.py
│   └── main.py
├── static/
│   └── index.html
├── .env.example
├── .gitignore
└── requirements.txt
```

SQLite-файл `restaurant.db` создаётся при первом запуске сервера; демо-столики и меню добавляются автоматически.

## Запуск локального демо

Требуется Python 3.10 или новее.

```bash
python3 -m venv .venv
# Bash / Zsh:
source .venv/bin/activate
# Fish:
source .venv/bin/activate.fish
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env` для локального режима:

```dotenv
BOT_TOKEN=
WEBAPP_URL=
ADMIN_TELEGRAM_ID=111111
DEV_MODE=true
DEV_TELEGRAM_ID=111111
```

`DEV_MODE=true` разрешает браузерную проверку через ID из заголовка; откройте `http://127.0.0.1:8000/?demo=1`. Чтобы открыть админку локально, `DEV_TELEGRAM_ID` должен совпадать с `ADMIN_TELEGRAM_ID`. Не включайте dev-режим на общедоступном сервере.

Запустите сервер из корня проекта:

```bash
uvicorn app.main:app --reload
```

Приложение доступно на `http://127.0.0.1:8000`, документация API — `http://127.0.0.1:8000/docs`. Локально можно проверить каталог, корзину, бронирования, заказы, отзывы и админ-панель. В локальном режиме Telegram-бот не нужен.

## Запуск бота и Telegram Mini App

1. Создайте бота через [@BotFather](https://t.me/BotFather) и укажите полученный токен в `BOT_TOKEN`.
2. Разместите приложение на сервере с HTTPS либо временно откройте локальный порт через HTTPS-туннель (например, Cloudflare Tunnel или ngrok). Telegram Web App требует публичный HTTPS URL.
3. В `.env` задайте `WEBAPP_URL=https://ваш-домен/` и свой числовой `ADMIN_TELEGRAM_ID`. Установите `DEV_MODE=false`.
4. Настройте домен Mini App в BotFather при необходимости, затем запустите сервер:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

5. В отдельном терминале, из корня проекта и с тем же `.env`, запустите polling бота:

```bash
python -m app.bot
```

6. Откройте бота в Telegram и отправьте `/start`. Кнопка откроет Mini App. Пользователь получает роль администратора только при совпадении Telegram ID с `ADMIN_TELEGRAM_ID`; API повторно проверяет роль для каждого административного действия.

Бот использует long polling, поэтому отдельный webhook и публичный endpoint для бота не нужны. Для постоянной эксплуатации запускайте API и процесс бота как отдельные сервисы под supervisor/systemd/Docker. Не публикуйте `.env` и не оставляйте `DEV_MODE=true`.

## Возможности

- Каталог меню с категориями и корзиной.
- Акции, бронирование столика, привязка заказа к брони, доставка, отзывы.
- Предзаказ к активной подтверждённой брони; доставка требует адрес и контактный телефон. Оба варианта заказа отображаются в админ-панели.
- Рейтинг и короткие отзывы Stories в главном экране берутся из карточки 2GIS; актуальная лента и публикация отзыва открываются на странице заведения.
- Панель администратора: список/фильтр броней, подтверждение и отмена, просмотр заказов, добавление и мягкое удаление позиций меню.
- Проверка пересечений броней на уровне API и атомарно в SQLite-триггере. Пересекающиеся интервалы запрещены для броней со статусом `pending` или `confirmed`; граничные интервалы вроде 18:00–20:00 и 20:00–21:00 разрешены.
- Заказы сохраняют снимок названия и цены позиции на момент оформления.

## Импорт меню Stories

Проверить структуру меню без изменения базы:

```bash
python3 parser.py --dry-run
```

Импортировать или обновить меню и локальные пути изображений в SQLite:

```bash
python3 parser.py
```

Парсер читает встроенные данные каталога Stories, сохраняет оригинальные ссылки на фото и связывает блюда с файлами из `pictures/stories_kamiqr/`. Повторный запуск обновляет записи по ID источника, не создавая дубликаты. Позиции без подходящего локального фото используют корневой `logo.png`. Отдельно запустить импорт можно командой `python3 seed_db.py`.

Для подготовки облегчённых версий локальных фотографий установите `cwebp` и `ffprobe`, затем выполните `python3 optimize_images.py`. Оригиналы сохраняются; приложение автоматически отдаёт WebP-версии до 1440 px, если они доступны.

## API

Клиентские маршруты: `GET /api/me`, `GET /api/menu`, `GET /api/offers`, `GET /api/tables`, `GET /api/bookings/mine`, `POST /api/bookings`, `POST /api/orders`, `POST /api/reviews`.

Для `POST /api/orders` доставка требует `address` и `contact_phone`. Тип `dine_in` требует `booking_id` пользователя со статусом `confirmed` и непросроченным временем брони.

Администраторские маршруты: `GET /api/admin/bookings?status_filter=pending&booking_date=YYYY-MM-DD`, `PATCH /api/admin/bookings/{id}`, `GET /api/admin/orders`, `POST /api/admin/menu`, `DELETE /api/admin/menu/{id}`. Полная схема доступна в Swagger на `/docs`.

Для SQLite используется `create_all` и установка триггеров при старте. Для production-миграций и сложного управления схемой добавьте Alembic; это демо не заменяет платёжную интеграцию, уведомления, защиту от спама и production-политику хранения данных.
